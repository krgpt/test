# KRWA Team — 웹사이트

공매 자산 방어·증식 솔루션 소개 웹페이지. 원본 `../index.html`(Tailwind CDN 단일 파일)을
인터뷰 전문·요약본 내용으로 확장하고, 의존성 없는 정적 사이트로 재구성했습니다.

## 실행

빌드 과정 없음. `index.html`을 브라우저로 바로 열면 됩니다.
로컬 서버로 확인하려면:

```powershell
python -m http.server 5500
# http://localhost:5500
```

영상은 저장소에 두지 않고 YouTube 임베드로 제공합니다 (아래 참고).

## 히어로 영상 (YouTube)

소개 영상(5분 30초)은 저장소에 두지 않고 **YouTube 임베드**로 제공합니다.
`youtube-nocookie.com` 도메인을 사용해 재생 전에는 추적 쿠키를 남기지 않습니다.

### 설정 방법 — 한 줄만 바꾸면 됩니다

1. `C:\Users\Nathan\Desktop\공매\공매.mp4` 를 YouTube에 업로드합니다.
   공개 범위는 **"일부 공개(Unlisted)"** 로 두면 검색에는 안 뜨고 웹사이트에서는 정상 재생됩니다.
2. 영상 주소에서 ID를 복사합니다.

   ```
   https://www.youtube.com/watch?v=dQw4w9WgXcQ
                                   ^^^^^^^^^^^  ← 이 부분
   ```

3. `index.html`의 히어로 섹션에 붙여넣습니다.

   ```html
   <section id="hero" class="hero" data-youtube-id="dQw4w9WgXcQ">
   ```

전체 URL을 그대로 붙여넣어도 자동으로 ID만 추출합니다.
**값이 비어 있으면** 배경 영상과 재생 버튼이 모두 자동으로 숨겨지고,
기존 그라디언트 히어로가 그대로 표시됩니다. (현재 상태)

### 동작 방식

**1) 배경 자동재생 (무음)** — 방문 즉시 히어로 뒤에서 무음·반복 재생됩니다.
컨트롤·키보드·전체화면을 모두 끄고 `pointer-events: none`을 적용해 클릭이 영상으로 가지 않으며,
위에 스크림(`--video-scrim`)을 덮어 본문 가독성을 유지합니다.

> **소리와 함께 자동재생하는 것은 불가능합니다.** Chrome·Safari·Firefox 모두 사용자 조작 없는
> 소리 있는 자동재생을 차단합니다. 표준 우회 방법은 없으며 `mute=1` 자동재생만 허용됩니다.

**2) `▶ 소개 영상 보기` 버튼** — 모달에서 **소리와 함께** 컨트롤이 있는 상태로 재생됩니다.
사용자 클릭 이후라 소리 재생이 허용됩니다. ESC·배경 클릭·닫기 버튼으로 종료되며,
닫으면 iframe을 제거해 재생과 네트워크를 완전히 정리합니다. 포커스 트랩이 적용되어 있습니다.

### 성능 처리

플레이어를 무조건 불러오지 않습니다. 배경 영상은 아래를 **모두** 통과할 때만 iframe을 생성합니다.

| 조건 | 이유 |
|---|---|
| `prefers-reduced-motion` 꺼짐 | 모션 민감 사용자 배려 |
| 화면 폭 ≥ 768px | 모바일 데이터 보호 (모바일은 배경 영상 생략) |
| `saveData` 꺼짐, 회선이 2G 아님 | 저속·종량제 회선 보호 |

모달 영상은 버튼을 누르기 전까지 아무것도 불러오지 않습니다.
또한 히어로가 화면 밖으로 나가거나(IntersectionObserver) 탭이 백그라운드로 가면
(`visibilitychange`) YouTube IFrame API에 `postMessage`로 일시정지를 보냅니다.
API 스크립트를 따로 로드하지 않고 `enablejsapi=1` + `postMessage`만 사용합니다.

### 왜 저장소에 영상을 두지 않았나

원본 mp4는 64.5MB입니다. GitHub 100MB 제한 아래라 푸시 자체는 되지만,
**한 번 커밋하면 히스토리에 영구히 남아** 나중에 압축본으로 교체해도 저장소 용량이 줄지 않습니다.
Git LFS는 GitHub Pages가 포인터 파일을 그대로 서빙해 영상이 깨지므로 이 경우엔 부적합합니다.
YouTube는 대역폭 비용이 없고 적응형 스트리밍·모바일 최적화가 기본 제공됩니다.

`.gitignore`에 `*.mp4`와 `assets/video/`를 넣어 대용량 영상이 실수로 커밋되는 것을 막아두었습니다.

## 다크 / 라이트 모드

헤더 우측의 해/달 아이콘 버튼으로 전환합니다.

**동작 방식**

1. **최초 접속** — OS·브라우저의 `prefers-color-scheme` 설정을 그대로 따릅니다.
2. **수동 전환** — 버튼을 누르면 선택이 `localStorage['krwa-theme']`에 저장되고,
   이후 방문에서는 OS 설정보다 이 선택이 우선합니다.
3. **OS 설정 변경 추적** — 사용자가 직접 전환한 적이 없다면, 방문 중 OS 테마가 바뀔 때 실시간으로 따라갑니다.
4. **탭 동기화** — 여러 탭을 열어둔 상태에서 한 탭의 테마를 바꾸면 나머지 탭에도 반영됩니다.

**깜빡임(FOUC) 방지** — `index.html` `<head>`의 인라인 스크립트가 CSS 페인트 이전에
`<html data-theme="...">`를 세팅합니다. 이 스크립트는 **반드시 `<head>` 안, 스타일시트 링크 앞에**
있어야 하므로 위치를 옮기지 마세요.

**JS 비활성 환경** — `@media (prefers-color-scheme: dark)` 폴백이 있어 OS 설정에 맞는 테마로 표시됩니다.
(토글 버튼만 동작하지 않습니다.)

**테마별 색상 수정** — `assets/css/style.css` 1번 섹션의 세 블록:

| 블록 | 역할 |
|---|---|
| `:root` | 라이트 팔레트 (기본값 / no-JS 폴백) |
| `@media (prefers-color-scheme: dark) > :root:not([data-theme="light"])` | OS 다크 설정 폴백 |
| `:root[data-theme="dark"]` | 사용자가 직접 선택한 다크 (최우선) |

> 다크 팔레트는 2·3번 블록에 동일하게 들어갑니다. **값을 바꿀 때 두 곳 모두 수정**해야 합니다.

액센트 골드는 모드별로 다릅니다. 라이트 모드에서 `#e9c46a`를 흰 배경에 쓰면 명도 대비가
약 1.7:1로 판독 불가 수준이라, 라이트에서는 `--accent: #8a6516`(약 5.5:1)을 사용합니다.
주요 버튼도 라이트 모드에서는 골드 배경 대신 블랙 배경 + 흰 글자(`--accent-fill`)로 처리했습니다.

  필요 시 법률 검토 후 반영하시기 바랍니다.
- 푸터에 가정 예시·수익 미보장 고지 문구를 포함했습니다.
- `수수료정책.xlsx`(에이전트 수수료 조건)는 내부 자료로 판단해 페이지에 반영하지 않았습니다.

## 브라우저 지원

Chrome / Edge / Safari / Firefox 최신 버전. IntersectionObserver 미지원 환경에서는
애니메이션 없이 콘텐츠가 정상 노출됩니다. `prefers-reduced-motion` 및 인쇄 스타일 대응 포함.
인쇄 시에는 테마와 무관하게 항상 흰 배경 + 검은 글자로 출력됩니다.
`localStorage` 접근이 차단된 환경(시크릿 모드 등)에서도 오류 없이 동작하며,
테마 선택만 저장되지 않습니다.
